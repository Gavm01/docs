## One inbox

Open **Inbox** in the sidebar, or go to [https://agentclara.app/chats](https://agentclara.app/chats).

The inbox has two views: **Conversations** and **Tickets**.

If you see **Inbox Access Restricted**, you do not have permission. Ask an admin.

## Channels

The channel list is:

- **SMS**
- **Email**
- **Voice**
- **WhatsApp**
- **Instagram**
- **Facebook**
- **Chat Widget**

A channel only receives messages after you connect it.

| Channel | Where you connect it |
| --- | --- |
| SMS and voice | [Phone Numbers](/voice-calls/setting-up-voice) |
| WhatsApp, Instagram, Facebook | [Socials and apps](/inbox-channels/instagram) |
| WhatsApp setup in detail | [WhatsApp](/inbox-channels/whatsapp) |
| Website chat | [Chat widget](/teach-clara/website-chat) |
| GoHighLevel | [GoHighLevel](/inbox-channels/ghl) |

## Reply, or let Clara reply

Open a conversation to read it and reply. Clara replies from the agent you connected to that channel.

To see what she will say first, use **Chat Lab**.

## Schedule a call from the inbox

If you schedule a call, the form asks for **Date**, **Time**, **Timezone**, and **Select Agent**. Then click **Schedule Call**.

You must pick both a date and a time. If no agent exists yet, you see **No agents configured. Please create an agent first.**
