## What a lead webhook is

A lead webhook is a URL on your workspace. Another tool, such as a form or a CRM, sends a new lead to that URL.

Clara can then auto-call that lead. **Lead Calling Rules** on the agent control when she does. The card says **Control when Clara auto-calls new leads**.

Only one agent in the workspace is the lead handler. Turn **new leads** on for the agent that should make those calls.

## Get the URL

<Steps>

<Step title="Open Webhooks">
Go to [https://agentclara.app/settings/advanced/webhooks](https://agentclara.app/settings/advanced/webhooks).

You need permission to manage webhooks. If you do not, the page says so.
</Step>

<Step title="Find Lead Webhooks">
The section is **Lead Webhooks**. The line under it is **Incoming webhook URL for receiving leads from external systems.**
</Step>

<Step title="Generate the URL">
If none exists, you see **No webhook configured for this workspace yet.**

Click **Generate Webhook URL**. If one was turned off, the page says **Generate a new one to start receiving leads** and the button is **Generate New Webhook URL**.

You should see **Webhook URL generated**.
</Step>

<Step title="Copy it">
Click **Copy URL**. You should see **Copied to clipboard**.

The row shows **Status**, **Source**, **Last received**, and **Created**.
</Step>

</Steps>

Paste that URL into the tool that collects leads. Keep it private. Anyone with the URL can try to send events.

## Turn on auto-calling

Open **Agents**, then **Automation**.

Open **Lead Calling Rules**. Switch on auto-calls for new leads, and choose the **Lead Sources to Auto-Call**.

If the step says **Switch it on under Lead Calling Rules**, that is this switch.

## If nothing arrives

- **Last received** stays empty until a lead is sent.
- A webhook that already exists for the workspace cannot be created twice. You see **Webhook already exists for this workspace**.
- **Webhook URL is misconfigured** means generate it again.
