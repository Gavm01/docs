## Open API Keys

Go to [https://agentclara.app/settings/advanced/api-keys](https://agentclara.app/settings/advanced/api-keys).

The heading is **API Keys**. The line under it is **Manage API keys and access tokens**.

You need permission to view and manage keys. If you do not, you see **You don't have permission to view API keys** or **You don't have permission to manage API keys.**

## What this screen is

This is a store for secrets Clara uses with other services. The example in the form is `stripe`, `twilio`, or `resend`.

It is not a button that mints a key for a public Clara REST API.

## Add a key

<Steps>

<Step title="Click Add API Key">
The list is **Stored API Keys**. The page says **Keys are encrypted and only used from the backend.**

If the list is empty, you see **No API keys stored yet.**
</Step>

<Step title="Fill in the form">
**Service name**. Example: `stripe`, `twilio`, or `resend`.

**API key**. Paste your secret key.

**Description (optional)**. What the key is used for.
</Step>

<Step title="Save">
You should see **API key saved**.

The page says **Keys are never shown again after saving. Rotate them from your provider if needed.**
</Step>

</Steps>

The table columns are **Service**, **Description**, **Created**, and **Actions**.

Deleting a key shows **API key deleted**, or **Failed to delete API key** if it does not work.
