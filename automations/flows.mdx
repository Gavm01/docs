## Open Flows

In the sidebar, open **Flows**, or go to [https://agentclara.app/flows](https://agentclara.app/flows).

The heading is **Flows**. The line under it is **Manage customer pipelines, automate workflows — powered by AI.**

**Journeys** and **Workflows** in the address bar open this same page.

## The tabs

- **Pipelines**
- **Workflows**
- **Analytics**

Pick the agent at the top if the page asks for one.

## Put a contact in a pipeline

On **Contacts**, use **Add to Pipeline**.

If you see **No pipelines found. Create one in Flows first**, create the pipeline on this page, then go back to the contact.

You choose a pipeline and an **Entry Stage**.
