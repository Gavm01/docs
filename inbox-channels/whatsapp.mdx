## Where to start

Open **Integrations**. The page is the **Integrations Hub**.

You can also open [Socials & Apps](https://agentclara.app/integrations/socials-apps).

WhatsApp sits with Facebook and Instagram under communications. You need permission to change integrations. If you do not, you see **You don't have permission to change integrations.**

## Connect WhatsApp

<Steps>

<Step title="Open the WhatsApp card">
Start from the WhatsApp card. The helper is titled **Set up WhatsApp Business**.
</Step>

<Step title="Set the display name">
**WhatsApp display name** is your business name. This is what customers see.

Meta reviews it after setup. If it is rejected, you have to connect again with a different name.
</Step>

<Step title="Finish in Meta">
Meta asks for a phone number on the next screen. Copy yours from Clara, then type Meta's verification code into Meta's window.

The code is 6 digits. Click **Copy code** if you need to paste it.

When Meta has the number, type the 6-digit PIN you set for it. That finishes the connection.
</Step>

<Step title="Wait until it says connected">
You should see **WhatsApp connected** or **WhatsApp connected successfully**.

If it still says **Still registering**, you can close the window. Clara keeps watching and emails you when it is connected, or if something needs you.
</Step>

</Steps>

## If it fails

**Meta couldn't connect this number** means nothing was charged and nothing is half-connected. Start again from the WhatsApp card.

**Could not load Facebook** means refresh the page. If a popup was blocked, allow popups and try again.

Messages then show in the **Inbox** under **WhatsApp**.
