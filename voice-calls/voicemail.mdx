## Where voicemail is set

Open **Agents**, then **Routing**.

Find **Voicemail Handling**.

## When voicemail is detected

Pick one:

- **Hang up immediately**
- **Leave a voicemail message**
- **Hang up and follow outbound retry logic**

If you choose **Leave a voicemail message**, write the **Voicemail message**. Put &#123;&#123;first_name&#125;&#125; in the message **to personalise with the contact's name.**

If saving fails, you see **Failed to save voicemail message. Please try again.**

## Outbound calls

**Hang up and follow outbound retry logic** uses the retry rules on the outbound call. That setting lives with **Broadcasts**, not as a separate voicemail inbox.

## Hear it first

Open **Voice Lab** at [https://agentclara.app/test/voice](https://agentclara.app/test/voice) and place a test call before you turn this on for customers.
