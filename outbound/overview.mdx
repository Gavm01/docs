## Open Broadcasts

In the sidebar, open **Broadcasts**, or go to [https://agentclara.app/telephony/outbound](https://agentclara.app/telephony/outbound).

The same screen also opens from [https://agentclara.app/launch/outbound](https://agentclara.app/launch/outbound).

The heading is **Broadcasts**. The line under it is **AI-powered outreach, follow-ups, and campaigns — all from one place.**

You need an **Active Agent** selected.

## The tabs

- **Campaigns** — outbound campaigns. Click **New Campaign** when you are ready. See [Creating campaigns](/outbound/campaigns).
- **Bookings** — **Booking Health (24h)** and **Booking activity in the last 24 hours**. The counts are **Created**, **Cancelled**, **Rescheduled**, **Deduped**, and **Blocked**. If there are none, you see **No booking activity in the last 24 hours.**
- **Templates** — **Smart Outbound Templates**. The page says **Pick a ready-made playbook. Clara will handle the calling.** See [Call templates](/outbound/templates).
- **Settings** — **Retry Logic** says **Set up automatic retry behavior for failed calls**. **Compliance** says **Calling hours, allowed days, and regulatory safeguards**. If no agent is selected, you see **Select an agent to set up outbound settings.** Save with **Save Changes**. You should see **Outbound settings saved**. If it fails, you see **Failed to save outbound settings**.

## What this is not

One-to-one replies stay in the **Inbox**.

Automatic messages after a call are [Follow-ups](/teach-clara/follow-ups).

New leads from another tool use [Lead webhooks](/outbound/lead-webhooks).
