## Open Follow-ups

Go to [https://agentclara.app/followups](https://agentclara.app/followups).

The heading is **Follow-ups**. **Auto Follow-ups** says **Automatically message callers based on what happened**.

The tabs are **Templates** and **Settings**.

## Set them up

<Steps>

<Step title="Select an agent">
If none is selected, you see **Please select an agent to set up follow-ups.**

Pick the agent in the agent switcher first.
</Step>

<Step title="Check the channels">
The page points you at the pieces Clara needs:

- **Apps & CRM's** — connect the channels she uses to message and book
- **Phone Numbers** — get a number and enable calling and SMS
- **Chat Widget** — if you want the website widget as well
</Step>

<Step title="Save">
When it works, you see **Follow-up settings saved**.

If it fails, you see **Failed to save settings**.
</Step>

</Steps>

This is separate from **Broadcasts**, which is for campaigns, and from **Lead Calling Rules**, which auto-call new leads.
