## What you can connect

Clara does not ask you to call a public conversations API from these docs. The screens that exist are:

- **API Keys**, where you store a secret from another service, such as Stripe, Twilio, or Resend
- **Webhooks**, where other tools send events into Clara, including leads

Open those from the links below. Both need the right permission. If you do not have it, the page says so.

<CardGroup cols={2}>
  <Card title="API keys" icon="key" href="/api-reference/authentication">
    Store a secret from another service. Clara keeps it encrypted.
  </Card>
  <Card title="Webhooks" icon="webhook" href="/api-reference/endpoint/webhooks">
    Receive events and leads from tools you already use.
  </Card>
</CardGroup>

## Where they sit in the app

**API Keys:** [https://agentclara.app/settings/advanced/api-keys](https://agentclara.app/settings/advanced/api-keys)

**Webhooks:** [https://agentclara.app/settings/advanced/webhooks](https://agentclara.app/settings/advanced/webhooks)

Workspace Settings also has **Advanced Settings** under **Developer Tools**. That item is for admins.
