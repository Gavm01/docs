## Open Webhooks

Go to [https://agentclara.app/settings/advanced/webhooks](https://agentclara.app/settings/advanced/webhooks).

The heading is **Webhooks**. The line under it is **Set up webhook endpoints and integrations**.

The page also says webhooks let external tools, such as Stripe, Meta, and CRMs, send events into Clara in real time.

You need permission. If you do not have it, you see **You don't have permission to view webhooks** or **You don't have permission to manage webhooks.**

## Lead webhooks

**Lead Webhooks** is the URL for new leads from an outside system.

If you have no URL yet, click **Generate Webhook URL**. You should see **Webhook URL generated**. Then click **Copy URL**.

The row shows **Status**, **Source**, **Last received**, and **Created**.

Full steps are in [Lead webhooks](/outbound/lead-webhooks).

## Other integrations

**Configured Webhook Integrations** lists each integration and its endpoint.

The table columns are **Integration**, **Endpoint**, **Status**, **Last Delivery**, and **Actions**.

If nothing is set up, you see **No webhook integrations are configured yet.**

Above the table, **Webhook Health Overview** shows **Connected Integrations**, **Failed Events (recent)**, and **Events Received (24h)**.

## Connect a provider

The page's own steps are:

1. **Create a webhook in your provider.** Examples on the page: Stripe, Twilio, Meta, HubSpot, Salesforce.
2. **Use the endpoint URL from the table.** Copy the exact URL.
3. **Add your signing secret** in your backend so signatures can be checked.

Keep these URLs secret. Anyone with the endpoint can try to send events.

## If events fail

- Check the provider's webhook logs.
- Confirm the endpoint URL matches exactly, with no extra spaces.
- Confirm the signing secret.
- Make sure the endpoint is publicly reachable.
- Use **Open Support & Debug** on the page if you need to look further.

A test that fails shows **Test ping failed**.
